# 自律型受付案内ロボット「ソータ（Souta）」

## ロボットの名前と意味
- ロボット名: **ソータ**（漢字表記: **颯太** / 英語表記: **Souta**）。
- 名前の意味: 「ソータ（颯太）」という名前は、日本語で**「広大な空」「大空」（広大なる青空）**という意味を持っています。どこまでも広がる空のように、広い心で親切に、そして元気に来訪者のみなさまをお迎え・案内できるようにという願いが込められています。

## 開発元と研究チーム
- 開発組織: **OpenWorkShop LAB**（オープンワークショップ・ラボ）。
- 所属機関: **郵政通信工科大学（PTIT） 電子工学第1学部（FEE1）**。
- 指導教員: **ホアン・ソン博士（TS. Hoàng Sơn）**（電子工学第1学部 制御・自動化学科 専従講師）。
- 目的: ロビーや受付での自律走行、来訪者案内、および音声AIによるスマートな対話サービス。

## 技術仕様と構成
- **移動プラットフォーム**: 差動駆動方式（Differential Drive）。
- **制御マイコン**: ESP32（シリアル通信経由でROS 2と接続）。
- **ソフトウェア基盤**: ROS 2（Robot Operating System 2 Humble）。
- **ナビゲーションと自己位置推定**: Nav2、SLAM（2D LiDARおよびホイールエンコーダ）。
- **センサー群**: 2D LiDAR、RGB-Dカメラ（Intel RealSense）、IMU慣性計測ユニット、ホイールエンコーダ。
- **インタフェース**: タッチスクリーン・キオスクUI（PyQt5）、マルチモーダル音声対話システム。

## 主な機能
1. **自律ナビゲーションと目的地案内**: PTITキャンパス内の各教室や研究室、受付へ来訪者を自動で先導・案内します。
2. **人物検知と手振り認識**: カメラにより手を振った来訪者を検知し、自律的に近寄って受付を開始します。
3. **障害物自動回避**: 人や障害物をリアルタイムに検知し、安全に減速・回避します。
4. **多言語AI音声対話**: ベトナム語、英語、日本語、中国語、韓国語の5言語に対応したリアルタイム音声対話。
