# Agent Working Rules

1. **Giải thích rõ ràng**: Luôn giải thích nguyên nhân, logic và phương án khắc phục chi tiết trước khi tiến hành chỉnh sửa code.
2. **Xin xác nhận từ người dùng**: Luôn hỏi ý kiến và chờ người dùng xác nhận thông tin/kế hoạch trước khi thực hiện bất kỳ chỉnh sửa code hay triển khai nào.
